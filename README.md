# Tu.investigación

Página web de Tu.investigación: asesoría para tesis y trabajos de suficiencia profesional.

## Archivos
- `index.html` – la página
- `style.css` – los estilos
- `images/glasses.jpg` – la foto principal

## Publicar con GitHub Pages
1. Sube estos archivos a un repositorio nuevo en GitHub.
2. Ve a **Settings → Pages**.
3. En **Source** elige **Deploy from a branch**, rama `main`, carpeta `/ (root)`.
4. Guarda. En 1–2 minutos tu página estará en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.
